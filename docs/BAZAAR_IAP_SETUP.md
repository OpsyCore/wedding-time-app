# اتصال پرداخت درون‌برنامه‌ای کافه‌بازار

## کالاهای ساخته‌شده در پیشخان

| شناسهٔ کالا | محصول | نوع بازار | دسترسی |
|---|---|---|---|
| `pro` | پرو یک‌ساله | یک‌بار خرید | ۳۶۵ روز از زمان انقضا/خرید قبلی |
| `premium` | پرمیوم مادام‌العمر | یک‌بار خرید | بدون انقضا |

محصول سالانه پس از تأیید سرور در Poolakey مصرف می‌شود تا خریدار بتواند پس از پایان اعتبار دوباره همان کالا را بخرد. خرید مادام‌العمر مصرف نمی‌شود.

## کلید RSA

کلید RSA پیشخان، **کلید عمومی** است. کلید «تخفیف پویا JWT» برای خرید معمولی لازم نیست و نباید وارد برنامه شود.

در GitHub مخزن، یک Repository variable به نام `BAZAAR_RSA_PUBLIC_KEY` بسازید:

`Settings → Secrets and variables → Actions → Variables → New repository variable`

مقدار آن را عیناً از بخش «پرداخت درون‌برنامه‌ای → تنظیمات → کلید RSA» کپی کنید. Workflow همین مقدار را هنگام ساخت APK به برنامه می‌دهد. این متغیر عمومی است؛ هیچ رمز حساب یا کلید خصوصی را در آن قرار ندهید.

## تأیید امن خرید و فعال‌سازی

برنامه نتیجهٔ خرید Poolakey را به Firebase callable function با نام `verifyBazaarPurchase` می‌فرستد. Function روی سرور امضای RSA رسید را بررسی می‌کند، حساب Firebase و شناسهٔ محصول را تطبیق می‌دهد، از ثبت دوبارهٔ یک purchase token جلوگیری می‌کند و سپس پلن را روی کاربر و مراسم فعال او می‌نویسد. این Function از Firebase Admin SDK استفاده می‌کند؛ قواعد Firestore اجازهٔ ارتقای مستقیم پلن به خود کاربر را نمی‌دهند.

برای استقرار:

1. Firebase CLI را نصب و وارد حساب Firebase شوید.
2. از ریشهٔ مخزن اجرا کنید: `firebase use wedding-time-8240d`
3. سپس `firebase deploy --only functions` را اجرا کنید. در نخستین استقرار، مقدار پارامتر `BAZAAR_RSA_PUBLIC_KEY` را از پیشخان وارد کنید.
4. استقرار Cloud Functions ممکن است به فعال‌بودن طرح صورتحساب Blaze در پروژهٔ Firebase نیاز داشته باشد.

فایل `.env` یا هر مقدار تنظیمی را به Git اضافه نکنید. کلید RSA عمومی است، اما تنظیم آن باید فقط در متغیرهای build و backend انجام شود.

## ساخت APK

Workflow ساخت APK از Repository variable بالا استفاده می‌کند. اگر این متغیر تنظیم نشده باشد، برنامه ساخته می‌شود ولی خرید را آغاز نمی‌کند و پیام تنظیم‌نبودن کلید را نشان می‌دهد. پس از تنظیم کلید، یک APK جدید بسازید و خرید را با حساب آزمایشی بازار و محصولات فعال‌شده تست کنید. `app-release.apk` یونیورسال را برای بازار بارگذاری کنید.
